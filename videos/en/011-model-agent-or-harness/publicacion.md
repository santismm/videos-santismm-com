## Sources and caveats

- **Primary source:** SANTISMM Labs, the game ["¿Modelo, agente o arnés?"](https://labs.santismm.com/model-agent-harness) (v1.0, August 2026; read 18-11-2026). The game only exists in Spanish (the English labs page lists it as "Model, agent or harness?"). **Every quote in this video and in this file is our translation.** On screen they are labelled "translated". The content loads in the browser; it was read from the page's code and by playing all 12 cases in an automated browser.
  - **Definitions** (the game's three buttons):
    - Model (Modelo): "La capacidad que predice y genera" → "The capability that predicts and generates".
    - Agent (Agente): "La entidad que percibe, decide y actúa" → "The entity that perceives, decides and acts".
    - Harness (Arnés): "El sistema que conecta contexto y herramientas" → "The system that connects context and tools".
  - **The question for each case:** "Which layer is the main subject of this description?"
  - **Caveat (the game's footer):** "Classify the subject described, not the whole brand. Products like Codex, Devin or Claude Code combine model, agent and harness in different proportions." The game's intro adds: "a product can contain all three".
  - **The game's closing summary** (basis for the thesis): "model is capability; agent, goal-directed behavior; harness, the system that makes it possible and governable". The lab's description: "Classify the layers of an AI system and understand their responsibilities."
- **The three quiz cases** (the lab's text and explanation, translated; shown in full on screen, summarized in the voiceover):
  - **Lab case 2 (PRODUCT):** "Codex receives a task, inspects a repository, edits files and runs tests until the task is done." → **Agent**. "There is a goal, perception of the environment, chained decisions and actions. It can use a model and live inside a harness."
  - **Lab case 6 (CONTROL):** "A layer injects instructions, limits permissions, logs traces and cuts off high-impact actions." → **Harness**. "The layer governs how the model or the agent is used. It is the harness, not the base intelligence."
  - **Lab case 9 (ARCHITECTURE):** "Claude Sonnet 4.6 run without memory, tools or an outer loop." → **Model**. "Without the system that gives it persistence or the ability to act, it is still model inference." The voiceover says "Claude Sonnet" without the version number.
- **Context (not quoted in the video):** the [Harness Engineering hub](https://santismm.com/en/harness-engineering) defines it as "the practice of designing, building and optimizing the scaffolding (tools, memory, prompts, environment and control loop) that turns a model's raw capability into reliable, goal-directed action", and adds: "Harness engineering is to agents what platform engineering is to cloud applications."
- **No figures:** the only number in the video is the game's "12 cases".
- **Relation to #01:** episode 01 explained what the harness is and how much it can move a result. This one does not repeat that data: it teaches how to tell the three layers apart using the game's cases.
- **Animation:** the stacked slabs, the quiz buttons and the rotary selector are visual metaphors. The countdown leaves about a second and a half to guess before each answer.
